# Shinobi Keys

タイピング修行 — 忍者テーマのタイピング練習アプリ。

## 技術

- React / TypeScript / Vite
- Tailwind CSS
- Vitest / ESLint

## 開発

```bash
npm install
npm run dev
npm run lint
npm run test
npm run build
```
