# Shinobi Keys

忍者テーマの時間制タイピング修行アプリです。表示された日本語をローマ字入力し、落下する敵手裏剣を迎撃します。1問ずつ出題され、成功または失敗のあと次の敵が現れる寿司打方式です。

## ゲーム概要

- **時間制ゲーム**です。制限時間が 0 になると終了します
- **ステージ進行はありません**（最初から最後まで難易度設定のみ）
- **寿司打方式**: 問題（日本語・ローマ字）が敵手裏剣と一緒に落下 → タイピング → 成功または失敗 → 現在の敵を削除 → 次の敵を生成
- 同時に 2 体以上の敵は出ません
- プレイヤーは画面下部で待機します（移動操作はありません）
- 敵手裏剣は真下へ落下します（横移動なし）。日本語・ローマ字は敵に追従し、回転は手裏剣のみです
- 通常の成功は味方手裏剣迎撃、接触直前だけ緊急の刀迎撃
- 操作はタイピングと一時停止のみ
- 失敗すると HP が減りますが、**HP が 0 でもゲーム終了しません**（時間切れまで続行）
- ノーミスで問題をクリアすると連続成功数が増えます。4 / 8 / 12 問で時間とコインの報酬があり、12 問後は進捗が 0 から再スタートします
- 1 文字でもミスすると連続成功の進捗は 0 になります（すでに得た追加時間・コインは減りません）
- 時間内にどれだけ多く倒せるかをスコアで競います
- 一般的なローマ字の表記ゆれに対応します（例: 「すし」は `sushi` / `susi`）

## 主な機能

- 難易度 3 種（修行生 / 忍者 / 忍頭）
- 各難易度 200 問以上・合計 600 問以上の問題データ
- 難易度ごとの制限時間（修行生 60 秒 / 忍者 90 秒 / 忍頭 120 秒）
- **難易度は落下速度で変化**（修行生はかなり遅い / 忍者は普通 / 忍頭は速い）
- 問題の長さも難易度設定だけで決まります（ステージ進行による難化なし）
- 夜の修行場をテーマにした固定背景
- ブラウザの戻る・進む操作に対応（ゲーム中の戻るは終了確認）
- 問題・ローマ字は敵手裏剣と一緒に落下表示（手裏剣だけ回転）。スコア・HP・コイン・時間は小さめの HUD
- プレイ記録の localStorage 保存
- コイン獲得（撃破マイルストーン・連続成功報酬・成績ボーナス）
- ノーミス連続成功で時間・コイン報酬（4問:+1秒/+1コイン、8問:+2秒/+2コイン、12問:+3秒/+3コイン。12問後は0から再スタート）
- 1文字ミスで連続成功の進捗は0に戻る（獲得済みの追加時間・コインは減らない）
- 残り時間に上限なし（報酬で初期制限を超えて増やせる）
- コイン用の専用ゲージはなし（連続成功の時間報酬ゲージのみ）
- 忍者屋敷でのキャラクター購入・変更
- Web Audio による効果音・簡易 BGM
- 一時停止 / 再開（ボタン・Esc・タブ非表示）
- 音量・ミュート・モーション設定
- 遊び方・設定・記録・忍者屋敷画面

## ローマ字入力の例

| 表示 | 受け付ける入力例 |
|------|------------------|
| すし | `sushi`, `susi` |
| しのび | `shinobi`, `sinobi` |
| つき | `tsuki`, `tuki` |
| 感想 | `kansou`, `kannsou` |
| がっこう | `gakkou`（促音） |
| ラーメン | `ra-men`（長音は半角ハイフン `-`） |

長音記号「ー」は半角ハイフン `-` で入力します（例: ケーキ → `ke-ki`）。

## 難易度

| ID | 表示名 | 制限時間 | 落下速度 | 問題 |
|----|--------|----------|----------|------|
| `trainee` | 修行生 | 60 秒 | かなり遅い | 短い単語中心 |
| `ninja` | 忍者 | 90 秒 | 普通 | 普通の単語 |
| `master` | 忍頭 | 120 秒 | 速い | 長い単語も追加 |

- 合計問題数は 600 問以上です
- ステージによる速度・問題の変化はありません
- 一時停止中は残り時間のカウントも止まります
- 終了条件は時間切れのみです

## コイン

- 一定数撃破するごとにマイルストーン報酬があります（同一プレイ中、同じマイルストーンは1回のみ）
- ノーミス連続成功でもコインを得ます（4/8/12問の地点のみ。コイン用ゲージはありません）
- ゲーム終了時にスコアに応じた成績ボーナスがあります
- リザルトに獲得コイン合計（撃破・連続成功・成績）を表示します

### 計算式

| 種類 | 計算 |
|------|------|
| 撃破マイルストーン | `5 + マイルストーン番号 × 5`（例: 1回目 → 10、2回目 → 15） |
| 成績ボーナス | `score / 500` の整数部分 |

## 忍者屋敷（キャラクター）

タイトル画面の「忍者屋敷」から開けます。

| 名前 | 価格 | 固有能力 |
|------|------|----------|
| 見習い忍者 | 0 コイン（初期所持） | 基礎修行：補正なし |
| 紅蓮の忍者 | 100 コイン | 紅蓮の連撃：獲得スコア +10% |
| 蒼影の忍者 | 200 コイン | 蒼影の守り：被ダメージ -20%（最低1） |
| 黄金の忍頭 | 500 コイン | 黄金の褒賞：撃破マイルストーンコイン +20% |

## 記録保存

- ブラウザの **localStorage** に保存します（キー: `shinobi-keys-data`）
- **サーバーへ送信しません**（オフライン完結）
