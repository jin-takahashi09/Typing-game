# Shinobi Keys

忍者テーマのタイピング修行アプリです。落下する日本語をローマ字入力で撃ち落とし、防衛を守りながらスコアと正確性を伸ばします。

## ゲーム概要

- 日本語の下に代表ローマ字が表示されます
- キーボードでローマ字を入力してターゲットを撃破します
- 一部の語は複数表記（例: `shi` / `si`）を受け付けます
- 防御力が 0 になるとゲームオーバーです
- ステージクリアや成績に応じてコインを獲得し、忍者屋敷でキャラクターを購入できます

## 主な機能

- 難易度 3 種（修行生 / 忍者 / 忍頭）
- WPM・正確率・経過時間の表示
- プレイ記録の localStorage 保存（ベスト・履歴・前回比較）
- コイン獲得（ステージクリア報酬・成績ボーナス）
- 忍者屋敷でのキャラクター購入・変更
- Web Audio による効果音・簡易 BGM
- 一時停止 / 再開（ボタン・Esc・タブ非表示）
- 音量・ミュート・モーション設定
- 遊び方・設定・記録・忍者屋敷画面

| 表示 | 受け付ける入力例 |
|------|------------------|
| しのび | `shinobi`, `sinobi` |
| つき | `tsuki`, `tuki` |
| おちゃ | `ocha`, `otya` |
| がっこう | `gakkou`（促音） |
| らーめん | `ramen`（長音） |

## 難易度

| ID | 表示名 | 特徴 |
|----|--------|------|
| `trainee` | 修行生 | 短い問題・ゆったり |
| `ninja` | 忍者 | 標準 |
| `master` | 忍頭 | 長い問題・速い落下 |

## コイン

- ステージをクリアするとコインを獲得します（同一プレイ中、同じステージの報酬は1回のみ）
- ゲーム終了時にスコアに応じた成績ボーナスがあります
- リザルト画面に、ステージクリア報酬・成績ボーナス・今回の合計・所持コインが表示されます

### 計算式

| 種類 | 計算 |
|------|------|
| ステージ報酬 | `5 + クリアしたステージ番号 × 5`（例: STAGE 1 → 10、STAGE 2 → 15） |
| 成績ボーナス | `score / 500` の整数部分 |

## 忍者屋敷（キャラクター）

タイトル画面の「忍者屋敷」から開けます。

- 初期キャラクター「見習い忍者」は無料で、最初から所持済みです
- コインを使って他のキャラクターを購入できます
- 購入済みキャラクターへいつでも変更できます（ゲーム中の変更はできません）
- 選択中のキャラクターはタイトル・ゲーム・一時停止・リザルトに反映されます
- 見た目は CSS・装備・シルエット差分で表現しており、外部画像素材は使っていません
- **各キャラクターに固有能力**があり、プレイ開始時に選択中の能力が固定されます（プレイ中は切り替わりません）

### キャラクター一覧

| 名前 | 価格 | 固有能力 |
|------|------|----------|
| 見習い忍者 | 0 コイン（初期所持） | 基礎修行：補正なし |
| 紅蓮の忍者 | 100 コイン | 紅蓮の連撃：獲得スコア +10% |
| 蒼影の忍者 | 200 コイン | 蒼影の守り：被ダメージ -20%（最低1） |
| 黄金の忍頭 | 500 コイン | 黄金の褒賞：ステージクリアコイン +20% |

### 能力の計算

| 能力 | 計算 |
|------|------|
| 紅蓮の連撃 | `Math.floor(スコア × 1.1)`（撃破スコアに1回だけ） |
| 蒼影の守り | `Math.max(1, Math.ceil(ダメージ × 0.8))`（防衛壁ダメージ） |
| 黄金の褒賞 | `Math.floor(ステージ報酬 × 1.2)`（成績ボーナスコインには非適用） |

能力はプレイ開始時点の選択キャラクターで固定されます。WPM・正確率・ローマ字判定には影響しません。

## 記録保存

- ブラウザの **localStorage** に保存します（キー: `shinobi-keys-data`）
- スコア・WPM・正確率・履歴などが残ります
- 所持コイン・購入済みキャラクター・選択中キャラクターも localStorage に保存されます
- 記録画面から確認付きで履歴・ベストを削除できます
- 記録削除後も、音量などの設定に加えて **所持コイン・購入状況・選択キャラクターは残ります**
- **サーバーへ送信しません**（オフライン完結）

## 音・一時停止・設定

- 音は Web Audio API で生成します（外部音声ファイルなし）
- ブラウザの自動再生制限があるため、最初の操作後に音が有効になります
- ゲーム中は「一時停止」ボタンまたは Esc
- タブを非表示にすると自動一時停止し、戻っても自動再開しません
- 設定画面で音量・ミュート・モーション（システム / 軽減 / 通常）を変更できます

## プライバシー

プレイ記録・設定・コイン・キャラクター情報はご利用の端末内にのみ保存されます。アカウント機能やクラウド同期はありません。

## 現在の制限事項

- オンラインランキング・ユーザー登録なし
- BGM / SE は簡易オシレータ生成（外部素材なし）
- キャラクター見た目は CSS・装備表現のみ（外部画像素材なし）
- すべてのローマ字表記ゆれを網羅しているわけではありません
- 参考デザイン HTML（`sample/simple_typing_game.html`）は参照のみで、アプリ本体ではありません
