# Shinobi Keys

忍者テーマの縦落下迎撃アクションタイピング修行アプリです。画面上のさまざまな横位置から真下へ落下する敵手裏剣に表示された日本語をローマ字入力し、通常は味方手裏剣で迎撃します。接触直前の成功だけ刀で斬ります。

## ゲーム概要

- プレイヤー忍者は画面下部で待機します（移動・ジャンプ・しゃがみの直接操作はありません）
- 敵手裏剣は画面内（HUD 下）から真下へ落下します（出現する横位置は毎回変わります）
- **同時にプレイ可能な問題は常に 1 体**です。成功・失敗のあと、現在の問題を片付けて次の問題をすぐ生成します
- キーボードでローマ字を入力し、最後まで成功すると迎撃方法が自動選択されます
  - 通常の成功: 味方手裏剣を敵の位置へ投げて迎撃（近距離でも手裏剣）
  - 味方手裏剣は敵位置へ斜めに飛びます
  - 接触直前の成功だけ: 緊急の刀迎撃
- Space や方向キー、W/S でキャラクターを操作する仕様はありません（操作は基本的にタイピングと一時停止のみ）
- 入力が間に合わず敵に接触すると **失敗** になります（コンボがリセットされ、失敗数へ加算され、次の問題へ進みます）
- **ゲーム終了は制限時間切れのみ**です。HP 表示・HP による終了はありません
- 一般的なローマ字の表記ゆれに対応します（例: 「寿司」は `sushi` / `susi`）
- 所持コインはゲーム画面上部に表示され、獲得時に数値が加算されます
- 撃破マイルストーンや連続成功、成績に応じてコインを獲得し、**ガチャ**でキャラクターを入手できます

## 主な機能

- 難易度 3 種（修行生 / 忍者 / 忍頭）
- 各難易度 200 問以上・合計 600 問以上の問題データ
- 難易度ごとの制限時間（修行生 60 秒 / 忍者 90 秒 / 忍頭 120 秒）
- 最初の問題が出る前、および問題が無い空白中はタイマーが止まります
- 長文ほど落下時間が長くなり、読める時間を確保します（出現は画面内・HUD 下）
- 問題の日本語・ローマ字の文字サイズは問題中ずっと一定です（入力途中で拡大縮小しません）
- 一般的な単語は漢字など自然な日本語表記で表示します（ローマ字入力は従来どおり）
- 夜の修行場をテーマにした固定背景（軽い装飾アニメのみ）
- ブラウザの戻る・進む操作に対応（ゲーム中の戻るは終了確認）
- WPM・残り時間・所持コイン・連続成功ゲージの表示（**HP は表示しません**）
- プレイ記録の localStorage 保存（ベスト・履歴）
- ガチャ（単発 / 10 連）と**忍録**によるキャラクター収集・選択
- Web Audio による効果音・簡易 BGM
- 一時停止 / 再開（ボタン・Esc・タブ非表示）。一時停止中は背景・敵・タイマーも停止
- 音量・ミュート・モーション設定（reduced motion では装飾アニメを軽減。敵の進行に必要な移動は停止しません）
- 遊び方・設定・記録・ガチャ・忍録画面（各画面左上から戻れる）

## ローマ字入力の例

| 表示 | 受け付ける入力例 |
|------|------------------|
| 寿司 | `sushi`, `susi` |
| 忍び | `shinobi`, `sinobi` |
| 月 | `tsuki`, `tuki` |
| 感想 | `kansou`, `kannsou` |
| 学校 | `gakkou`（促音） |
| ラーメン | `ra-men`（長音は半角ハイフン `-`） |

長音記号「ー」は半角ハイフン `-` で入力します（例: ケーキ → `ke-ki`）。長音を省略した入力（例: `ramen`）は正解になりません。余分な末尾文字（例: `sushii`, `kannsoud`）は正解になりません。

## 難易度

| ID | 表示名 | 制限時間 | 特徴 |
|----|--------|----------|------|
| `trainee` | 修行生 | 60 秒 | 短い言葉を中心に練習（200 問以上） |
| `ninja` | 忍者 | 90 秒 | 拗音や促音を含む言葉に挑戦（200 問以上） |
| `master` | 忍頭 | 120 秒 | 長い言葉や文章に挑戦（200 問以上） |

- 合計問題数は 600 問以上です
- 長文は難易度に応じて出題されますが、ローマ字長に応じて落下時間を延長します
- 一時停止中は残り時間のカウントも止まります
- リザルトの終了理由は時間切れです

## コイン

- 撃破数が一定数に達すると撃破ボーナスコインを獲得します（同一プレイ中、同じマイルストーンは1回のみ）
- 連続成功（4 / 8 / 12）で時間ボーナスとコインを獲得します
- ゲーム終了時にスコアに応じた成績ボーナスがあります

### 計算式

| 種類 | 計算 |
|------|------|
| 撃破ボーナス | `5 + マイルストーン番号 × 5`（例: 1 回目 → 10、2 回目 → 15） |
| 成績ボーナス | `score / 500` の整数部分 |

## ガチャ

タイトル画面の「ガチャ」から開けます。

- 単発 **100** コイン / 10 連 **900** コイン
- 中央に**巻物抽選**（忍びの巻物）UI を表示します
- レア度と排出率: N 55% / R 25% / SR 12% / SSR 6% / UR 2%（合計 100%）
- 被り時はコイン変換: N 10 / R 30 / SR 80 / SSR 200 / UR 500
- 排出率は画面下部に小さく横並びで表示します
- 演出のあと、結果は**画面中央のモーダル**（暗い背景）に表示されます
  - 通常: 巻物が浮く → 煙 → 開封 → キャラ
  - SR: 青紫の雷
  - SSR: 青紫＋金雷
  - UR: 金雷 → 紋章 → 強い発光 → キャラ
- 結果にはキャラ画像・名前・レア度・NEW / DUPLICATE・被りコインを表示します
- **閉じるまで結果は消えません**（reduced motion でも演出だけ短縮し、結果は維持）
- スキップ後も結果モーダルを表示します

キャラクターの確認・選択は**忍録**画面で行います（ガチャ画面に一覧はありません）。

## 忍録

タイトル画面の「忍録」から開けます。

- 全 **16 体**をカードグリッドで表示（所持 / 未所持）
- **所持**: カラー表示・名前・レア度・使用中バッジ。タップで詳細 →「この忍を使う」
- **未所持**: 白黒（シルエットは識別可能）・「未発見」「未入手」。選択不可
- 上部に所持数（例: `4 / 16`）を表示します
- 選択したキャラクターはタイトル・ゲーム・一時停止・リザルトに反映され、再読み込み後も維持されます

### キャラクター（16 体）

| レア | 人数 | 例 |
|------|------|----|
| N | 3 | 見習い忍者 / 影丸 / 翠霞 |
| R | 3 | 白銀 / 白夜 / 月光 |
| SR | 4 | 紅蓮の忍者 / 蒼影の忍者 / 風神 / 暁影 |
| SSR | 4 | 黄金の忍頭 / 雷影 / 黒炎 / 夜叉 |
| UR | 2 | 鬼面 / 天狐 |

見た目は CSS・装備・シルエット差分で表現しており、外部画像素材は使っていません。各キャラクターに固有能力があり、プレイ開始時に選択中の能力が固定されます。

### 能力の種類

| 型 | 効果の例 |
|----|----------|
| `none` | 補正なし（見習い忍者・影丸） |
| `scoreMultiplier` | 獲得スコア増加（紅蓮・蒼影の冴え・夜叉の劫火 など） |
| `stageCoinMultiplier` | 撃破ボーナスコイン増加（黄金・天狐） |
| `timeBonusSeconds` | 制限時間延長（月光・風神） |
| `comboMultiplierBonus` | コンボ倍率加算（白夜・暁影・鬼面） |

**HP 増加・HP 回復・ダメージ軽減（`damageReduction`）などの HP 依存能力はありません。**

能力はプレイ開始時点の選択キャラクターで固定されます。WPM・正確率・ローマ字判定には影響しません。

## 記録保存

- ブラウザの **localStorage** に保存します（キー: `shinobi-keys-data`）
- スキーマ version **3**（v2 から `gachaHistory` を追加。所持コイン・所持キャラ・選択・設定・記録は維持）
- 記録画面から確認付きで履歴・ベストを削除できます
- 記録削除後も、音量などの設定に加えて **所持コイン・所持キャラクター・選択キャラクターは残ります**
- **サーバーへ送信しません**（オフライン完結）

## 音・一時停止・設定

- 音は Web Audio API で生成します（外部音声ファイルなし）
- ブラウザの自動再生制限があるため、最初の操作後に音が有効になります
- ゲーム中は「一時停止」ボタンまたは Esc
- タブを非表示にすると自動一時停止し、戻っても自動再開しません
- 設定画面で音量・ミュート・モーション（システム / 軽減 / 通常）を変更できます

## プライバシー

プレイ記録・設定・コイン・キャラクター情報はご利用の端末内にのみ保存されます。アカウント機能やクラウド同期はありません。

## 現在の制限事項

- オンラインランキング・ユーザー登録なし
- BGM / SE は簡易オシレータ生成（外部素材なし）
- キャラクター見た目は CSS・装備表現のみ（外部画像素材なし）
- すべてのローマ字表記ゆれを網羅しているわけではありません
- 内部には旧仕様由来の `defense` 数値が残りますが、UI 表示・終了条件には使いません
- 参考デザイン HTML（`sample/simple_typing_game.html`）は参照のみで、アプリ本体ではありません
