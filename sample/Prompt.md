# ロックオンルール

ロックオン対象がない状態で英字キーが入力された場合：

1. 入力された文字から始まるターゲットを探す
2. 複数ある場合は、画面下部に最も近いターゲットを選ぶ
3. 対象をロックする
4. 1文字目を正解として進める

ロックオン中の場合：

- 次の正しい文字なら入力を進める
- 間違った文字ならミスとして処理
- ミスしても、Phase 2ではロックオンを解除しない
- 単語完成でターゲットを撃破し、ロックオンを解除

同じ開始文字の問題が複数あっても、最も危険なターゲットを優先してください。

ターゲットの危険度比較には、`targetsRef`の現在Y座標を使用してください。
